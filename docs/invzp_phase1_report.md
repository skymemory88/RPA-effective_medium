{12,16,20}, dpRng in {30,40,50} -- without literally requiring every one of the resulting 2x8x3x3=144

produces every FROZEN item-5/6 number (both refinement ladders at their production-default anchors, the 
offset spread "at every grid size", and the exact frozen finest-rung gate N=20/dpRng=50) while skipping

`MF_dipole.m`'s brute-force real-space lattice sum scales with the SPHERE of sites within the dpRng

## 2. Grid construction notes (`invz_phase1_qgrid.m`)

Offset `[0 0 0]` is built by a DIRECT `qVec_generator` call at grid=N (bit-identical to production's own 
unshifted grid); the other seven offsets shift one or more axes by HALF of that convention's own N-axis 
spacing, then wrap into one BZ. For **halfopen** this is provably identical (values and row order) to building 
a literal refined 2N grid and partitioning it by index parity (bisection is exact). For **legacy_inclusive** the 
literal 2N-grid partition would NOT reproduce the frozen item-1 worked example (N=16: 4096 vs 3375) at the `000` 
slot and would make the other seven offsets spuriously PASS item 1 -- so this builder instead applies the SAME 
half-step-shift rule to both conventions, which for legacy has the (informative) consequence that EVERY ONE of 
the eight legacy offsets shows the endpoint-duplicate defect, not just `000` -- see item 1 below and 
`invz_phase1_qgrid.m`'s header for the full derivation.
