Full-tensor 1/z tiers: A1, A2, and A3

What each approximation keeps, what problem it is meant to solve, and the gated route from the present A1 bridge to an A3 production theory.
Historical reference retained at the user’s request This guide explains the retired A1/A2/A3 tier vocabulary and records why the dense A3 route was stopped. It is not the active implementation plan on the invzt-multilevel-1z branch. The active specification is invzt_multilevel_1z_next_steps.md; the execution record is docs/execution/invzt_multilevel_1z_journal.md.
Terminology A1, A2, and A3 are repository approximation tiers. They are neither paramagnetic/ordered phases nor first-, second-, and third-order powers of 1/z. The physical phase is a separate verdict made from a converged, admissible state and its stability.

2. A1: the economical two-level bridge

Purpose

A1 retains the dominant low-energy transition as a two-level fluctuation problem. Its many-body correction is compressed into one scalar self-energy for each Matsubara frequency. Weak transitions can remain bare:

χ̃0 = χdom/(1 + Σ) + χrest.

A longitudinal medium K generates the moment sums λ, which update Σ. This is cheap, reduces to Jensen's scalar equations, and supports the existing scalar real-axis continuation.

What A1 is good for

  • Paramagnetic and near-continuous-boundary calculations dominated by one doublet.
  • Fast scans, transparent scalar limits, and comparison with the projected-spin implementation.
  • The boundary-exact linearized ordered handoff as the moment tends to zero.

Why tensor A1 stops deep in the ordered phase

  • A scalar Σ is forced through a multilevel tensor response.
  • The ordered two-level elastic factor has no unique dominant/rest assignment.
  • A multipole bare propagator has real zeros, so the ratio V/G0 can acquire artificial poles.
  • Multiple converged roots are not ranked by the fixed-point algorithm.
Current A1 boundary The full-tensor production driver is correctly fail-closed where no certified deep-ordered A1 state exists. Warm retries, Ewald summation, and projected missing-area logic cannot supply the missing tensor static theory or a physical root selector.

3. A2: isolate matrix-medium physics

Purpose

A2 asks a narrower question: what changes when the medium retains all Cartesian components, while the local fluctuation vertex remains the scalar A1 vertex? Given a local renormalized tensor χ̃0, it computes the full tensor lattice response and then the matrix medium

χ̄ = ⟨(χ̃0−1 − J(q))−1⟩q,
K = χ̃0−1 − χ̄−1.

The implementation uses active-subspace linear solves, not literal inverses. It preserves the physical off-frequency gyrotropic matrix structure. The code then feeds Kcc back into the same scalar A1 self-energy equation.

A2 is not a phase The current repository has a paramagnetic/symmetry-state point mode mode='a2'. It has no ordered A2 solver, phase dispatcher, or real-axis production route. A negative A2 mass means that the evaluated symmetry state is unstable; it does not define an “A2 ordered phase.”

4. A3: carry the multilevel vertex explicitly

Purpose

A3 removes the scalar compression. It evaluates the connected single-ion four-point vertex Γ(4), contracts it with the full matrix medium, and retains a component-labelled correction:

Vμν(n) = (1/2β) ∑l,ρσ Kρσ(l) Γ(4)μν ρσ(n,l).

The local response is resummed on a common active subspace in matrix form, avoiding division by a multipole G0:

G̃0 = G0(G0 + V)−1G0.

The matrix medium is recomputed from this response and the cycle V ↔ K is iterated to a fixed point. Centered operators put the connected elastic/Curie sector into the multilevel vertex itself. Consequently A3 does not need an arbitrary scalar assignment of Jensen's two-level elastic factor.

What A3 dictates

  • The correction is additive and component-labelled, not a scalar ratio.
  • The medium and vertex retain Cartesian indices and one representation.
  • Sigma_cc_equiv = Vcc/G0cc is diagnostic only.
  • A1 moment-form objects such as Σ, λ, α, and αm need not exist.
  • An ordered A3 theory must derive its own field and thermodynamic relations; it cannot inherit the A1 endpoint rescaling.

Full A3 versus the present ordered A3d hybrid

Full A3 dresses all retained vertex components. For the 136-state electronuclear space, the present dense four-point contraction is not computationally practical. The current ordered a3d route instead dresses a field-adapted rank-16 dominant cc vertex and leaves the rest response bare, while including that rest response inside the same matrix-medium fixed point. This is a coherent hybrid, but it is presently a Matsubara diagnostic around a bare-mean-field ordered state—not a completed A3 ordered thermodynamics.

There is also no matched PM A3d producer yet. The current PM mode='a3' full/legacy-dominant routes do not use the ordered A3d branch's identical fixed-rank basis and rest-offset contract. A continuous A3d phase boundary therefore requires a new PM map with the same vertex rank, dominant projector, rest response, and resummation on both sides.

Computational warning At T = 0.1 K and the current Matsubara cutoff, the rank-16 compact vertex is already approximately 4.3×1011 kernel operations per distinct single-ion state. A 101-state sweep therefore starts near 4.3×1013, before field-derivative or path states are counted, and rank 24 exceeds the default work guard. The current cache evicts after six entries, but this is not a safe full-dress policy: six compact entries use about 100 MiB, whereas six full entries use about 7.93 GiB per worker. Full dress stores a roughly 1.32 GiB Cartesian and frequency pad at this grid even for a small-state toy, and currently has no byte preflight. The replacement contract caps retained Gamma4 data at 1.5 GiB per worker, evicts before a new allocation crosses that cap, and independently caps worker RSS at 4 GiB. The other pre-registered ceilings are 24 hours per 101-point sweep after a factor-two forecast margin and 512 MiB of persisted sweep payload. Static susceptibility coverage alone is not a vertex convergence test; connected-variance coverage can be much poorer.
Cost gate result: stopped The clean compact-kernel record measured 1687 s for an uncached, JIT-warmed, untiled rank-16 build at T = 0.1 K, B = 3 T, and Ecut = 10 meV, projecting 7.43 h at the Ecut = 40 production grid. A 101-state sweep is therefore not expected to pass the present budget unchanged. On twelve workers, nine build waves and the factor-two margin require at least a 5.58× rank-16 speedup; N4 projections raise this to floors of 28.22× at rank 24 and 89.17× at rank 32. The existing rank-24 measurement was about 2.6× slower than that fit, making 73.35× the evidence-informed rank-24 prior until remeasurement. The commonly quoted roughly-35× figure is the serial, no-margin comparison, not the twelve-worker gate. A repeat of the unchanged executable kernel projected a slower 9.917 h/build, but overlapped an unrelated MATLAB job and is retained only as an upper bound. The formal optimistic 7.43 h basis still forecasts 133.74 hours for the margin-adjusted 101-state sweep, versus the frozen 24-hour ceiling. No exact contraction prototype has passed the identity, 10-11 equivalence, complexity, and forecast sub-gate. The recorded outcome is therefore stop_cost; A3-1/A3-2 and production dispatch are not authorized.

6. How the A3 route will be achieved

Current boundary Steps 1 and 2 below are complete. Step 2 stopped the present route on cost. Steps 3–9 are retained as the specification a future exact algorithm must satisfy, not as authorized work. Resuming requires new exact-compression evidence or a separately designed and labelled approximation tier.
  1. Freeze the current map — complete. Small deterministic A3/A3d tests now expose the residual, consistent co-state, status, and requested/realized rank.
  2. Reconcile cost, then screen feasibility — stopped. Dense cost is confirmed; the 101-state forecast fails by 5.573× and no exact compression prototype passes its sub-gate.
  3. Lock the theory contract. Prove the two-level ordered reduction through the declared 1/z order and the continuous-boundary limit.
  4. Expose one immutable A3 map. If the feasibility gate passes, separate context construction, one V → Vnew evaluation, iteration, and physical-domain diagnostics.
  5. Establish physical rank convergence. Within the authorized budget, measure vertex-rank, Matsubara, lattice, and resummation-scheme convergence at frozen boundary and deep-ordered states.
  6. Match the two phase producers. Build PM and ordered A3d maps with the identical fixed-rank dominant/rest convention before interpreting a boundary.
  7. Derive the A3 field response and ordered thermodynamics. Determine whether the field differential uses the fixed-V response or the total derivative of the self-consistent V map, then derive a selector or retain unranked components.
  8. Build zero-field, continuation, and phase layers. Only after the owning gates, add an invariant zero-field limit, matrix real-axis continuation, and A3 dispatcher. Without an ordered selector, production remains PM-only.
  9. Validate end to end. Require residual/co-state, rank/cutoff, build-budget, forward/reverse continuation, serial/parallel, causality, and clean-session reproduction gates at T = 0.1 K before any production declaration.
