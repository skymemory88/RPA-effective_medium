Projected-spin 1/z calculation for LiHoF4

This directory contains the scalar, projected-spin calculation. It retains three production streams: the phase boundary, uniform spectra, and q-path spectra. ODD corrections are retained. Audit drivers, cached results, field-angle experiments, and the alternative bare ordered route were removed in the July 2026 reduction.

Ordered-state rule. There is one ordered calculation: the Jensen-consistent static closure and HMF↔H relation. If that state is unavailable, the code masks the point; it never substitutes a bare mean-field moment.

Run the calculation

Entry pointPurposeUser-facing knobs
invz_run_phase_diagram.m Independent Bc(T) and Tc(B) cuts Ts, Bs, useODD, gridN, dipoleBackend, useParallel
invz_run_spectra.m Uniform field sweep or fixed-field q-path spectra T, fields, w, qpath, Bq, wq, gridN, dipoleBackend, plotting and solver budgets

Both drivers add this directory, the repository root, and invz_common to the MATLAB path. Run them from the MATLAB editor or with run(...). Persistent coupling caches are off by default, and the repository cache directory contains only .gitignore.

The ordered solver owns its HMF inversion and static EMT closure as local functions in invz_solve_point_ordered.m. They are implementation stages, not separate public entry points.

The local response and Hamiltonian construction live in invz_common. The projected branch deliberately uses a scalar longitudinal (cc) propagator; it does not duplicate the full-tensor branch.

Current operational status

The phase-boundary stream is retained as the working result stream. The active debugging target is the spectra stream: the Jensen ordered closure does not converge over every requested ordered-field column. Such columns are reported as phase=0 and remain NaN; this is the failure to diagnose, not a plotting or cache convention. No fallback state is inserted.

State selection

invz_solve_auto first tries the Jensen ordered solution. It accepts a paramagnetic solution only when it is converged and locally stable (crit > 0). Its phase labels are:

  • 1: accepted Jensen ordered state;
  • 2: accepted stable paramagnet;
  • 0: no accepted state; spectra are masked.

The RPA response has an independent bare-mean-field phase selector owned by invz_chi_realaxis: the PM mass 1-Jcc0*chi0cc0 selects the branch, and below its zero the ordered state solves hz=Jcc0*<Jz>. The RPA state therefore changes phase at its own critical field rather than reusing the state selected by the 1/z solver. The field map exports phase_rpa, rpa_mass_pm, and Bc_rpa separately.

ODD path

useODD=false selects the original scalar cc model. useODD=true constructs the off-diagonal dipolar blocks once with invz_odd_blocks, rebuilds the longitudinal modes with invz_odd_deltaJ/invz_odd_modes, and applies the uniform -d shift once inside the point solver. The incomplete variable-moment Tier-2 route has been removed. useODD is exposed by the phase-boundary driver; the spectra driver currently runs the ordinary non-ODD projected model.

The retained production ODD path is static. Low-level odd_retarded/odd_retarded_exact options remain isolated cross-checks and are not selected by either production driver.

Backend constraint. The retained ODD geometry is currently built by the brute-force real-space dipolar sum. Therefore Ewald cannot be the sole global implementation unless ODD geometry is first ported and validated. The ordinary non-ODD coupling builder supports both backends.

Coupling contract

The drivers use a zero-offset half-open cubic grid and drop the complete Gamma row. gridN is the only quadrature control: 16 is a debugging resolution, while reported phase-boundary values require rerunning a declared grid ladder or calling invz_odd_zero_field with multiple grid sizes for its linear-in-1/N endpoint extrapolation.

dipoleBackend='ewald' is the production default, with fixed controls alpha=0.3, r_cut=16, g_cut=3, and boundary='conducting_k0_omitted'. 'bruteforce' is retained as a mathematically transparent debugging reference; dpRng controls its real-space cutoff. ODD geometry currently uses the brute-force construction internally regardless of the ordinary backend setting.

q-path meaning

The production q-path observable uses the uniform ferromagnetic projection J(q)=vTJcc(q)v, with v=(1,1,1,1)/2. This is the single-mode dispersion used by the projected mean-field/RPA approximation. invz_jq_path supplies the directional long-wavelength limit at Gamma-equivalent points. The optional sorted eigenvalue branches remain exploratory: their index is not a tracked physical mode through crossings.

Deliberately removed

  • ordered_1z='bare', forced-moment dispatch, ordered-route selection, and diagnostic recovery heuristics;
  • field tilt, in-plane rotation, tensor-reference, C4-fit, and field-angle scan plumbing in this projected branch;
  • static-domain scans, trace/report scripts, convergence experiment drivers, and obsolete solver wrappers;
  • the incomplete ODD variable-moment Tier-2 route and its Gaussian-dressing helpers;
  • the isolated strict-functional prototypes and previous convergence diagnostic/execution trees;
  • checked-in/generated cache data and the duplicate ODD diversion in invz_jq_modes.

The validated in-plane vector_ab implementation remains in invz_common/invz_single_ion.m because the full-tensor branch uses it. Its projected-branch results and restoration instructions are retained in docs/invz_projected_field_orientation_recovery.md.

Scope

In scope: scalar cc-channel projected 1/z phase boundaries and spectra, Jensen ferromagnetic closure, q-path dispersion, hyperfine structure, the Σ=0 overlay, sample-shape handling already present in the scalar theory, and static ODD.

Out of scope: arbitrary field orientation in the projected branch, full-tensor propagation, neutron form factors/intensities, ODD variable-moment or full-tensor mode mixing, and silent fallback to approximate ordered states.
