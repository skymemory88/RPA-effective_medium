Projected-spin 1/z calculation for LiHoF4

Reference-only copy on the full-tensor branch. The user has certified the projected-spin branch as fully working, and it is outside the invzt-multilevel-1z implementation scope. This README is retained as module documentation; projected convergence plans, journals, and diagnostic reports are deliberately not duplicated into the clean tensor documentation set. Their source-of-record is projected commit 29d4117.

This directory contains the scalar projected-spin calculation for phase boundaries, uniform spectra, and q-path spectra. The ordered state uses the Jensen-consistent static closure and HMF↔H relation. ODD corrections remain available for the phase-boundary stream.

Current production status. At T=0.1 K, the factor-one missing-area member produces a smooth, finite susceptibility over the complete 101-point linspace(0,9,101) field sweep. Exact zero and the final ordered-side 4.68 T sample are handled by explicit fail-closed policies. The driver currently uses missingAreaFactors = 1.0; the wider three-factor sensitivity ensemble remains available as a diagnostic. The result is a labeled controlled approximation; strict full_profile remains available and unchanged.
No silent fallback. A field is emitted only from an accepted Jensen ordered state or an accepted stable paramagnet. The missing-area and retry paths are explicit options with exported provenance; they never substitute a bare mean-field moment.

Meaning of the missing-area factor

If the certified component begins at he, the unresolved lower contribution is represented as

A_f = f h_e r(h_e)
H_0(h) = A_f + integral_{h_e}^{h} r(s) ds

For the declared linear completion, r(0)/r(h_e) = 2*f - 1. The tested sensitivity factors [0.75 1 1.5] therefore represent endpoint ratios [0.5 1 2]. Factor 1 is the current production member. The driver keeps the wider list as a commented diagnostic option because only factor one passes the 4.68 T boundary contract. These are shape-sensitivity assumptions, not probabilities, fitted material constants, or confidence limits.

Exact zero field

The electronic doublet is degenerate at exact zero, so its numerical basis can make a basis-dependent transition weight exactly zero. The solver rejects the unresolved two-level endpoint without committing it, evaluates the certified positive-HMF suffix, and uses algebra in which the removable M2 cancellation is performed before numerical evaluation. The exact-zero missing-area spectrum is finite and continuous to 1e-6 T. Strict full_profile still masks that endpoint.

Frozen field retries

Both retry policies operate on an immutable cold pass. A recovered point is output-only and can never seed another recovery.

  • Two-sided adjacent retry: an interior cold mask is solved independently from accepted ordered fields on both sides. Both results must pass the original gates and agree. This recovers the 0.36 and 0.45 T holes on the audited grid.
  • Ordered-boundary retry: the last cold phase==0 point below an accepted PM field may use two untouched lower ordered sources. It additionally requires an independently converged negative PM mass, one matching unbridged component, D_uni and Fprime margins, the original residual and physical-mass gates, and a finite real-axis spectrum. Cold phase==2 points are never eligible.

On the current 101-point grid, the boundary retry recovers the factor-one 4.68 T state from the frozen 4.50 and 4.59 T states. In the separate three-factor diagnostic, factors 0.75 and 1.5 do not satisfy the full retry contract there. The production driver therefore emits the supported central spectrum without presenting a complete three-member interval.

The ordered solver owns its HMF inversion and static EMT closure as local implementation stages in invz_solve_point_ordered.m. Failed candidates never overwrite the last accepted continuation state.

q-path restriction. The missing-area ensemble is implemented for uniform field maps, not q paths. Set useMissingAreaApproximation=false before requesting a q-path. The driver fails explicitly if both are requested.

State and phase selection

invz_solve_auto first tries the Jensen ordered state. It accepts a paramagnet only when that solve is converged and locally stable (crit > 0):

  • phase=1: accepted Jensen ordered state;
  • phase=2: accepted stable paramagnet;
  • phase=0: no accepted state; the spectrum is masked unless an enabled retry subsequently satisfies its complete contract.

The RPA response has its own bare-mean-field phase selector in invz_chi_realaxis. It exports phase_rpa, rpa_mass_pm, and Bc_rpa separately and does not reuse the 1/z-selected phase.

Coupling and ODD contract

The drivers use a zero-offset half-open cubic grid and drop the complete Gamma row. gridN is the quadrature control. Reported phase-boundary values require a declared grid ladder or the endpoint extrapolation provided by invz_odd_zero_field.

dipoleBackend='ewald' is the ordinary production default, with fixed Ewald controls in the driver. 'bruteforce' remains a transparent reference. The retained ODD geometry is currently built by the brute-force real-space sum, so Ewald cannot be the sole implementation until that geometry is ported and validated.

useODD=false selects the original scalar cc model. useODD=true constructs the off-diagonal dipolar blocks once and applies the retained static ODD correction. The incomplete variable-moment Tier-2 route remains out of production.

q-path meaning

The q-path observable uses the uniform ferromagnetic projection J(q)=vTJcc(q)v with v=(1,1,1,1)/2. This is the single-mode dispersion of the projected mean-field/RPA approximation. Optional sorted eigenvalue branches are exploratory and are not tracked physical modes through crossings.

Interpretation and remaining limitation

The completed central susceptibility is a controlled numerical result on one declared branch. It is not an exact thermodynamic selection proof. The production hybrid combines the full electronuclear bare response with an electronic two-level vertex, and no same-ion stationary free-energy functional has been derived for that hybrid. This limitation is separate from the former masking problem and should not be described as its numerical root cause.

Evidence and scope

The projected implementation and its complete diagnosis, executed plan, journal, and diagnostic index are preserved on branch invzp-exec-convg-plan at commit 29d4117. They are not active instructions on this full-tensor branch. Tensor documentation is indexed by docs/invzt_documentation_index.md.

In scope: scalar cc-channel projected 1/z phase boundaries and spectra, Jensen ferromagnetic closure, hyperfine structure, uniform and q-path responses, the Σ=0 overlay, retained sample-shape handling, and static ODD. Out of scope: arbitrary projected-branch field orientation, full-tensor propagation, neutron form factors, ODD variable-moment/full-tensor mixing, and silent fallback to an uncertified ordered state.
